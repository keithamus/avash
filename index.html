avash

A BlurHash replacement, which uses a single 48 px AV1 frame with the container headers stripped. This page can be used to encoding the hash using rav1e via wasm, the resulting hash can be reconstructed using a tiny library (avash.js), whith we-wraps the bytes back into an AVIF image for the browser to decode.

Images with similar fidelity as the BlurHash tend to be a few characters smaller, while images taking up the same number of bytes as BlurHash tend to expose more details of the image, making it actually more useful.
